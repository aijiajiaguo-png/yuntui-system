操作使用说明

一、怎么下单付款
1. 选好商品，填你的微信号或 QQ 号，点「立即购买」，会生成一个订单号——请保存好，查单和售后都要用。
2. 加客服 QQ 3921567550，微信 / 支付宝转账订单金额，转账时备注订单号。
3. 转完点「我已付款，通知客服确认」，客服确认收款后发货。
4. 发货后在下方「查单 / 取码」输入订单号查询：卡密类商品直接显示卡密，代充类商品按备注提示查看。

· 美区 / 港区 Apple ID：收到账号、密码和密保后，在 App Store 登录使用，仅用于下载应用；不要登录 iCloud，不要改密码。
· Claude 中转 API：收到 API 地址和密钥后，填到你用的客户端里使用；额度到账后请及时使用。
· ChatGPT Pro 5X 月卡｜iOS 礼品卡：收到礼品卡代码后，在 App Store 兑换到余额，再用余额开通 Pro；收到后请立即激活，不要囤。
· ChatGPT Pro 10x｜菲区订阅：付款后加客服 QQ，提供你的 ChatGPT 账号信息，由客服直接帮你开通；开通后请查看账号。
· Codex GO 月卡：付款后加客服 QQ，提供你的账号信息，官方直充到你的账号；仅无订阅的免费号可充。

· Codex Team 周卡车位：付款后加客服 QQ，提供你的邮箱 / 账号信息，客服把你拉进 Team 席位；可与 Plus 并存。

· Plus 成品号｜菲区半价实付：收到账号后直接登录；不要改密码和 2FA；建议固定设备登录。
